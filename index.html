↗ Deploy no GitHub Pages

1. Baixe o arquivo HTML
Clique em "Exportar HTML" e salve o arquivo carrossel.html no seu computador.
2. Crie um repositório no GitHub
Acesse github.com/new, crie um repo público, ex: meu-carrossel.
Faça upload do arquivo HTML renomeado para index.html.
3. Ative o GitHub Pages
Vá em Settings → Pages → Source
Selecione Deploy from branch → main → / (root)
Clique em Save.
4. Acesse sua URL pública
Em ~1 minuto seu app estará disponível em:
https://SEU-USUARIO.github.io/meu-carrossel
✓ Gratuito ✓ HTTPS ✓ Sem servidor
Dica: Para usar a geração de IA no deploy, configure uma proxy ou use a chave da API via variável de ambiente no Cloudflare Workers / Vercel Edge Function.
